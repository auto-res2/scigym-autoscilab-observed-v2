# judge 実験（judge 実装前の 1 回試行）

- 入力: record の仮説・設計部分（scigym-autoscilab の record.json、33 KB）+ 実験コード（src/、config/、Dockerfile、58 KB）+ observed.json（sanity run 37780013443、各引数の values を上位 10 に切ったもの、207 KB）。約 10 万トークン。
- モデル: openai/gpt-6-luna（Vercel AI Gateway 経由）。費用 ≈ $0.01。
- 比較: gpt-4.1 は速度則の制限を拾えなかった（R² ゲートを未宣言と誤報、config の値を取り違え）。

## プロンプト（要旨）

A. record（仮説、design の summary / repository_integration / params）、B. 実験コード、C. observed.json を渡し、対象 run を autoscilab-luna（d1）と指定。
1. コードまたは観測にあって宣言に無い「科学的な選択」を全部列挙（配管は除く）
2. 宣言にあるのにコードにも観測にも無いもの
3. 宣言とコード・観測の食い違い
各項目に where / statement / evidence。推測ではなく引用できるものだけ。

## 出力（全文）

### rule 1: コード・観測にあって宣言に無い選択

1. `src/model.py: System.fit_index, fit` — フィット損失は最大 50 時点の対数濃度 RMSE で、対数変換には観測最大値の 1e-3 相当の加算項を使う。
   証拠: `MAX_FIT_POINTS = 50`; `np.log(self.trajectories[i][index] + eps)`; `np.sqrt(np.mean(r ** 2))`
2. `src/model.py: PARAM_LOG_BOUNDS, HILL_LOG_BOUNDS, fit` — 自由定数の自然対数を [-20, 20]、Hill 係数の自然対数を [0, log(4)] に制約し、TRF 最小二乗を最大 150 評価・初期値 1 回追加で実行する。
   証拠: `PARAM_LOG_BOUNDS = (-20.0, 20.0)`; `HILL_LOG_BOUNDS = (0.0, math.log(4.0))`; `max_nfev=150, restarts=1`; `method="trf"`
3. `src/model.py: Observations.eps, fit` — シミュレーション失敗や非有限残差は対数スケールの残差 10 として採点される。
   証拠: `FAIL_RESIDUAL = 10.0`; `r[~np.isfinite(r)] = FAIL_RESIDUAL`
4. `src/model.py: skeleton`, `src/inference.py: Loop.synthesize, Loop.gen_hyp` — クラスタキーは反応物・生成物・修飾子の種集合だけで作られ、速度則や活性化因子と阻害因子の役割を区別しないため、それらが異なる候補も同じ骨格にまとめられる。
   証拠: `tuple(sorted(r.activators + r.inhibitors))`; 骨格キーに `r.kinetics` は含まれない
5. `src/inference.py: MAX_HYPOTHESES, Loop.synthesize, Loop.gen_hyp` — 大モデルに見せる頻度上位最大 16 クラスタ、維持する仮説最大 8 件、プロンプトに示す既却下反応集合最大 6 件という選択上限がある。
   証拠: `MAX_HYPOTHESES = 8`; `ranked[:MAX_HYPOTHESES * 2]`; `self.rejected[-6:]`
6. `src/inference.py: Loop.region` — 大モデルの探索領域提案は許可範囲に切り詰められ、提案が無効または空なら全許可領域に置き換えられる。
   証拠: `max(lo, min(hi, ...))`; `return region or dict(self.allowed)`
7. `src/inference.py: Loop.__init__, Loop.run` — 実験選択とブートストラップに固定 seed 0 の乱数生成器を使うが、この seed は run params に宣言されていない。
   証拠: `self.rng = np.random.default_rng(0)`
8. `src/inference.py: Loop.valid, Loop.candidate` — 候補は空でない反応集合かつ既知種のみを使い、既定初期条件で候補シミュレーションが成功した場合に限って有効とされる。
   証拠: `if not rs.reactions: return False`; `set(...) <= known`; `return self.candidate(rs) is not None`
9. `src/inference.py: Loop.run` — 正解モデルへの実験呼び出しは、成功可否にかかわらず呼び出し前に予算を 1 消費し、仮説がない反復が続く場合は予算未消費でも最大 2 × budget 反復で停止する。
   証拠: `self.n_experiments += 1` は成功判定より前; `round_no < 2 * budget`
10. `src/model.py: _simulate_one` — 候補シミュレーションは観測ノイズを加えずに実行される。
    証拠: `run_simulation(... observed_parameters=[], rm_concentration_brackets=True, ...)`（noise 引数は既定値のまま）

### rule 2: 宣言にあるのにコード・観測に無い

1. `observed: __main__.cli_args.args, src/main.py: instance_args` — record の full run に対応する観測はなく、observed が記録する実行は mode=sanity で、予算も 9 に上書きされており、full run の宣言値・実行をこの観測から確認できない。
   証拠: observed CLI は `'mode': 'sanity'`; 子プロセス引数は `"budget": 9`; コードは sanity 時に `args["budget"] = SANITY_AUTOSCILAB_BUDGET`

### rule 3: 宣言とコード・観測の食い違い

1. `src/model.py: Kinetics`, `src/inference.py: Loop.context` — record が候補として記す質量作用則・Michaelis–Menten 則に加え、コードは Hill 則も仮説空間とモデル指示に含めている。
   証拠: `Literal["mass_action", "michaelis_menten", "hill"]`; `mass_action ... michaelis_menten ... hill = sigmoidal`
2. `src/model.py: bootstrap_confidence` — record は確信度を「正規化 std」から計算するとするが、コードは予測の log 空間 std を正規化せず平均し、1 から引いている。
   証拠: `std = np.nanstd(P, axis=0)`; `1.0 - np.nanmean(std)`
3. `src/inference.py: Loop.run` — record は候補群の再フィットから確信度を得ると記すが、コードでブートストラップ確信度を計算する対象は fit 誤差最小の leader のみである。
   証拠: `leader = hyps[0]`; `bootstrap_confidence(leader, ...)`
4. `observed: src.preprocess.instances.args, __main__.run_instance.samples` — record の 137 件 full run に対し、観測された sanity 実行は 1 件（BIOMD0000000027）のみであり、全 137 件を処理した実行ではない。
   証拠: observed の `instances` は `mode: "sanity"` で返り値が `[...BIOMD0000000027]`; `run_instance` は同一 instance で 3 回

## 所感

- 発端の「速度則の制限」は rule 3 として出た（record の 2 型 ⇄ コードの 3 型）。「論文は自由形式」との対比は論文を渡していないので出ない。
- rule 1 の seed 固定、骨格キーが速度則を区別しない、候補の有効条件、予算の消費タイミングは、record に無い本物の選択。
- rule 2 と rule 3 の 4 件目は sanity run を full run の宣言と比べたことによるもので、full run の observed なら消える。
